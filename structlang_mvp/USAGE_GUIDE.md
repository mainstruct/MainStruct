# StructLang 系统使用指南

## 📝 使用示例

### 示例 1：职场晋升问题

**用户输入**：
```
我在公司工作了3年，业绩一直不错，最近想申请晋升为高级工程师。
我跟老板提过两次，他总说"再看看"、"不着急"，态度很模糊。
我觉得自己能力够了，但不知道怎么推进这件事。
```

**AI 分析结果**：
```yaml
主体结构: ++-
  - 行动: + (主动提出晋升)
  - 能力: + (业绩不错，能力足够)
  - 态度: - (有些焦虑不确定)

客体结构: -?-
  - 行动: - (被动回应)
  - 能力: ? (不确定是否认可你的能力)
  - 态度: - (模糊推脱)

结构键: ++- vs -?-

意图向量:
  - 时间: 7/10 (比较着急)
  - 利益: 8/10 (晋升很重要)
  - 风险: 4/10 (中等风险容忍)
```

**策略推荐**：
```
策略: 主动展示成果，明确表达诉求，设定期限

推理依据:
你处于主动强势位置，但态度不够积极。老板被动且态度消极。
需要用具体的数据和事实打消对方疑虑，同时给出明确时间节点。

具体建议:
1. 准备一份工作成果报告（量化数据）
2. 预约正式会议，明确表达晋升意愿
3. 询问具体考核标准和时间节点
4. 表明如果长期得不到答复会考虑其他选择

成功率: 75%
风险提示: 避免过于激进，给对方思考时间

相似案例: 3个，都成功实现晋升
```

### 示例 2：消费维权问题

**用户输入**：
```
我在网上买了一个手机，收到后发现是翻新机。
联系商家要求退货，他说已经激活了不能退。
但我觉得他们隐瞒了是翻新机的事实，这是欺诈。
```

**AI 分析结果**：
```yaml
主体结构: ++-
  - 行动: + (主动维权)
  - 能力: + (有证据，权益明确)
  - 态度: - (气愤但有顾虑)

客体结构: +--
  - 行动: + (拒绝退货)
  - 能力: - (理亏，违法)
  - 态度: - (推卸责任)

结构键: ++- vs +--

意图向量:
  - 时间: 8/10 (比较紧迫)
  - 利益: 9/10 (涉及财产损失)
  - 风险: 5/10 (愿意投入精力维权)
```

**策略推荐**：
```
策略: 保留所有证据，向平台投诉或联系监管部门

推理依据:
你处于主动强势位置，商家虽然强硬但理亏。
用规则和证据压制，通过第三方平台或监管部门介入。

具体建议:
1. 截图所有聊天记录和商品描述
2. 拍摄开箱视频和产品照片
3. 联系官方售后进行鉴定
4. 凭鉴定报告向平台投诉
5. 必要时联系12315或市场监管局

成功率: 86%
风险提示: 注意证据的完整性和时效性

相似案例: 6个，5个成功退货并获赔
```

## 🎯 如何描述问题

### 好的问题描述应包含：

1. **背景情况**：你和对方的关系、事情的起因
2. **具体问题**：当前遇到什么困难
3. **双方状态**：你的想法、对方的反应
4. **你的诉求**：希望达到什么目标

### 描述模板

```
我[角色/身份]，[背景情况]。

当前遇到的问题是：[具体问题描述]

对方的态度/反应：[对方表现]

我的想法是：[你的诉求和顾虑]
```

### 示例对比

❌ **不好的描述**：
```
我老板不给我涨工资怎么办？
```

✅ **好的描述**：
```
我在公司做产品经理2年，负责的项目都很成功，
用户增长了3倍，营收翻番。

半年前我提出加薪，老板说年底再说。
现在到年底了，我再次提出，他又说公司今年效益不好。
但我知道公司刚拿了新一轮融资。

我想要至少涨薪20%，否则考虑跳槽，但担心太强硬会破坏关系。
```

## 💡 反馈的重要性

### 为什么要提交反馈？

1. **帮助系统学习**：你的反馈会更新策略成功率
2. **帮助他人**：成功经验会推荐给遇到类似问题的人
3. **完善案例库**：积累更多真实案例

### 如何提交有效反馈？

**结果分类**：
- **成功**：达到预期目标
- **部分成功**：部分达到目标
- **失败**：未达到目标

**详细说明**（可选但推荐）：
- 你具体怎么做的
- 对方的反应如何
- 最终达成了什么结果
- 有什么经验教训

**评分建议**：
- 5分：非常有帮助，完全解决问题
- 4分：有帮助，基本解决问题
- 3分：有一定参考价值
- 2分：帮助有限
- 1分：没有帮助

## 🔍 理解 AQT 结构

### A - Action（行动）

**+ 主动**：
- 主动发起、推动事情
- 掌握沟通节奏
- 示例：主动提出加薪、主动投诉

**- 被动**：
- 等待、回应
- 被对方牵着走
- 示例：等老板提、被动接受条件

**? 未知**：
- 行动意图不明确
- 难以判断主被动

### Q - Quality（能力/实力）

**+ 强势**：
- 有谈判筹码
- 能力被认可
- 有其他选择（BATNA）
- 示例：业绩优秀、有竞业offer

**- 弱势**：
- 缺乏筹码
- 处于不利地位
- 没有退路
- 示例：能力不足、急需用钱

**? 未知**：
- 实力对比不明确

### T - aTtitude（态度）

**+ 积极**：
- 愿意解决问题
- 态度友好开放
- 示例：积极沟通、愿意让步

**- 消极**：
- 拖延、推诿
- 态度恶劣、不配合
- 示例：不回复、找借口

**? 未知**：
- 态度不明朗

## 📊 理解意图向量

### 时间维度（0-10）

- **0-3**：不着急，可以慢慢来
- **4-6**：有一定时间压力
- **7-9**：比较紧迫
- **10**：极其紧迫，必须立即解决

### 利益维度（0-10）

- **0-3**：小事，利益不大
- **4-6**：有一定利益诉求
- **7-9**：重要利益相关
- **10**：核心重大利益

### 风险维度（0-10）

- **0-3**：零风险容忍，求稳
- **4-6**：可以承受一定风险
- **7-9**：愿意冒较大风险
- **10**：破釜沉舟，全押

## 📈 策略选择建议

### 如何选择策略？

1. **看成功率**：优先选择成功率高的策略
2. **看意图距离**：距离越小，情况越相似
3. **看风险提示**：评估自己是否能承受
4. **看相似案例**：参考他人经验

### 策略执行建议

1. **不要生搬硬套**：理解策略背后的逻辑
2. **结合实际情况**：灵活调整
3. **准备后备方案**：预备Plan B
4. **记录过程**：便于反馈总结

## ⚠️ 使用注意事项

1. **AI分析仅供参考**：最终决策需要你自己判断
2. **保护隐私**：不要输入敏感个人信息
3. **案例真实性**：系统推荐基于历史案例，但每个情况都独特
4. **法律问题**：涉及法律问题请咨询专业律师
5. **伦理底线**：不要用于违法或不道德目的

## 🎓 学习建议

1. **多看案例**：浏览案例管理页面，学习他人经验
2. **理解结构**：学会用AQT框架分析问题
3. **积累经验**：遇到问题先分析结构，再寻求策略
4. **反馈迭代**：使用后反馈，帮助系统进化
